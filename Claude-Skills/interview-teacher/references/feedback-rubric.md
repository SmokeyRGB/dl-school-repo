# Feedback Rubric

Given after the roleplay ends. Evidence-based only — every point of praise
or criticism cites the actual question or answer it refers to. No praise
without a specific example; no criticism without a concrete better
alternative.

## 1. Coverage

List the persona's hidden ground-truth items (problem, workaround, ranked
pain points, loaded phrase, delighter/non-obvious need) from
`persona-design.md`, and for each one mark:

- **Surfaced** — which question drew it out, quoted.
- **Missed** — what was said that hinted at it, and what question would have
  drawn it out (be specific, not "ask better questions").

## 2. Question-by-question or thread-by-thread review

Walk through the transcript using the tags collected during roleplay (see
`question-taxonomy.md`). For each notable moment:

- **Strong moves**: name the taxonomy type, quote the question, say
  concretely what it achieved (e.g. "repeating 'chaos' back — type B
  follow-up — is what got her to describe the actual argument, not just
  that one happened").
- **Weak moments**: quote the question, name the pitfall (leading, closed,
  compound, premature why, ignored loaded word, no debrief), explain what
  was lost, and give a rewritten version that would have worked better.

Don't review every single exchange if the interview was long — prioritize
the 3-5 most instructive moments in each direction.

## 3. Kvale's interviewer qualities

Rate briefly (in evidence, not a number score) against:
knowledgeable, structuring, clear, gentle, sensitive, open, steering,
critical, remembering, interpreting.

Only comment on the ones that were actually demonstrated one way or the
other in this specific interview — don't pad the list with qualities that
never came up.

## 4. Prioritized next steps

End with 2-3 concrete, prioritized suggestions for the next round — the
single highest-leverage change first. "Ask fewer closed questions" is not
concrete; "when she says something short like 'it's fine,' follow up with
a probing question ('could you say more about that?') instead of moving to
the next topic" is.

## 5. Offer another round

Ask if the user wants to run it again — same persona (to try the missed
threads) or a new one, optionally at a higher difficulty (see
`persona-design.md` §Calibrating difficulty).
