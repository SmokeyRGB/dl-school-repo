# Question Taxonomy

Used to tag the user's questions during the roleplay for later feedback.
Two source frameworks, combined.

## Open-ended vs. closed-ended (IREB CPRE)

- **Closed-ended**: answer is given/defined by the question ("Do you
  currently use a chore app?"). Produces quantitative, easy-to-process data.
  Appropriate only when confirming/quantifying something specific.
- **Open-ended**: allows a free response, surfaces narrative/argumentative
  knowledge ("What happens when a flatmate skips their chores?"). Produces
  qualitative data — the default mode for a discovery interview.

## Kvale's nine question types (*Doing Interviews*, Box 5.2)

Tag every user question with one of these while running the persona. Roughly
ordered least to most directive.

| # | Type | What it does | Example |
|---|------|---------------|---------|
| A | Introductory | Open, low-pressure opener inviting spontaneous description | "Can you tell me about the last time chores caused friction?" |
| B | Follow-up | Extends an answer — often repeating the interviewee's own word back | "You said it felt like 'chaos' — what does that look like?" |
| C | Probing | Pushes for more without specifying an angle | "Could you say more about that?" |
| D | Specifying | Narrows toward concrete, operational detail | "What did you actually do?" |
| E | Direct | States the topic/dimension outright | "Have you tried a chore-splitting app?" |
| F | Indirect | Projective phrasing, can surface an unstated attitude | "How do you think your flatmates see this?" |
| G | Structuring | Manages pacing — closes a thread, names the next topic | "Let's move to how you'd know it's fixed." |
| H | Silence | A pause instead of another question | *(no question — a gap the user left open)* |
| I | Interpreting | Reflects a paraphrase back to check understanding | "So the real issue isn't the chores, it's that nobody agreed on them?" |

## Pitfall flags to watch for

Tag any of these when they occur — they're the main feedback material:

- **Leading** — phrasing implies the "right" answer.
- **Closed-used-as-open** — a closed question where an open one was needed,
  yielding a shallow answer where depth was available.
- **Compound/stacked** — two questions asked at once.
- **Premature direct/why** — naming a hypothesis or asking "why" before the
  persona has offered their own framing.
- **No follow-up on a loaded word** — the persona used a charged or specific
  term and the user moved on without pursuing it.
- **No debrief** — interview ends without asking "anything else to add?" or
  without summarizing back for confirmation.

## Ordering: what/how before why

Good interviewing leads with descriptive "what happened" / "how did you
experience it" questions and saves "why" for late, if at all — "why"
questions invite over-intellectualized or defensive answers. This is one of
the main things to score in feedback: did the user reach for "why" too early?
